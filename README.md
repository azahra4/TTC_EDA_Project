# TTC Subway Delay Exploratory Data Analysis (EDA)

## Project Overview
This repository contains the Exploratory Data Analysis (EDA) for Milestone 3 of our Data Science course. Our objective is to analyze historical subway delay logs to prepare for predictive modeling.

## Data Source
We are using the official TTC Subway Delay Data provided by the City of Toronto. 
Dataset link: https://open.toronto.ca/dataset/ttc-subway-delay-data/

## Setup Instructions
1. Clone this repository to your local machine.
2. Run `pip install -r requirements.txt` to align your environment.
3. Download the dataset from the link above and place it in the root folder (it is included in `.gitignore` so it will not be pushed to GitHub).
